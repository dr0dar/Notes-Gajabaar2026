### Installing Kali Linux
- First download VMware and Kali Linux vmware image
- And open kali linux image in VMware

Here is the download link:
- [Vmware workstation pro](https://www.vmware.com/products/desktop-hypervisor/workstation-and-fusion)
-  [Kali LInux Image](https://www.kali.org/get-kali/#kali-virtual-machines)

After opening Linux in Vmware should run this command, it just make sure machine is UpToDate:
```shell
sudo apt update && apt upgrade
```

Note : Default username and password for Kali Linux images are **Kali** and **Kali**.
